# Screenshot

Taruh gambar di sini (dipakai README): `network.png`, `system.png`, `devices.png`, `alerts.png`.

Cara membuat: jalankan aplikasi, **tekan `P`** (mode Sembunyikan IP) supaya IP, MAC, SSID, dan nama PC tersamarkan, lalu tangkap
jendela (Win+Shift+S). Lebar yang bagus: 1480 px. Jangan unggah gambar yang masih menampilkan IP/MAC asli.
